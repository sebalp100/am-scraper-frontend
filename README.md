## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

### Prerequisites

To run this project you need:

- NPM
- Git
- Github account.
- Code editor (Visual Studio Code, Atom, etc.)

### Setup

Clone this repository to your desired folder:

cd my-folder
git clone https://github.com/sebalp100/am-scraper-backend

You can find the front-end repo here:
https://github.com/sebalp100/am-scraper-frontend

### Usage

To run the project, execute the following commands in your Ruby terminal:

`npm install` to install all dependencies.

`npm run dev` to start the Frontend server.

You should have the Frontend running now. You can visit http://localhost:5173/ in your browser to access the website.
